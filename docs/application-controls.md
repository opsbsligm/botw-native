# 掌机控制栏与输入

Deck 系统帮助的世界操作字母使用独立的普通字形，按打开游戏时的物理世界绑定生成，不再受菜单 A/B 字体切换影响；底部菜单仍 A 确认、B 返回。修改世界绑定后重启游戏以重新载入帮助页。只处理精确内容指纹匹配的本版本布局。两幅整机图和九幅教程局部图均以原纹理内容识别，不按尺寸盲换。教程动画高亮、所有语言和其他流程仍需逐场景实机验收。

帮助字母按原图标字号的 70% 显示，与旁边的动作文字协调；希卡之石教程的 View 按钮按原图 Minus 中心坐标对齐，使用留白裁切并检查像素边界，避免为了对位拉伸掌机。

帮助图的几何修正在运行时完成，不依赖仓库外的资源转换脚本。原始 1.6.0 布局与旧版已转换布局都有精确内容指纹；两者生成同一份内存布局，原始 RomFS 保持只读。步行、骑马和沙海象三组说明文字恢复原位置，只调整控制标记与连接线，保留游戏对多行说明的动画。未知布局、缺少节点、重复节点和无效几何不会部分写入。资源兼容验证与真实游戏各状态的显示验收分别记录。

点击角落的调节角标先展开快捷面板，再点击功能卡片、面板空白处或“展开完整设置”进入完整菜单。完整菜单可返回快捷面板，点击“收起”恢复角标。角标与面板短条均可拖动，松开后吸附到最近的边或角；也可选择八个停靠位置。菜单采用物理 Deck A 确认、B 取消；世界玩法保持原绑定。应用面板展开时捕获输入，收起时清除残留按下状态。游戏菜单范围与验证边界见 [菜单输入](menu-confirm.md)。

面板与下拉选项使用不透明深色背景，避免游戏文字透入设置内容；颜色和间距只在侧栏绘制期间生效，关闭后恢复原样式。角标自带柔和投影，雪原与天空等高亮画面上仍读得清；图标是三轨滑块的调节符号，不依赖任何字形。

完整菜单的列表在空白处直接上下拖动，滚动条关闭，改由列表右缘的细指示条显示位置：拖动时点亮，离开后淡出，页面无可滚动内容时不出现。列表下方不再有滚动按钮。

触摸经 Gamescope/X11 转换为普通鼠标事件时，也按按下位置确定完整手势归属：角标内部开始的拖动在移出旧边界后仍归应用，释放后停靠；世界中开始的拖动不会被路过角标截走。原生触摸与鼠标回退的应用手势期间暂停游戏输入和相对鼠标镜头，失焦或设备移除时清理归属。该路径需在实际游戏中单独回归，不能只用直接向 ImGui 注入事件的组件测试代替。

已识别为 Valve Steam Deck（Jupiter/Galileo）的设备自动采用触屏优先模式，保持指针绝对坐标，不自动锁进鼠标镜头；摇杆、游戏按键和原生六轴保持原路径。完整设置会说明当前模式并禁用不适用的鼠标镜头开关。其他设备保留原鼠标行为；`SAVAGEWIND_TOUCH_PRIORITY=0/1` 可明确覆盖检测结果。该选择只作用于当前启动环境，不重写玩家的鼠标偏好。实机开关对照已证明相对模式会把左侧角标起手坐标偏移到窗口底部；新默认配置仍须完整包回归。

取消拖动会清除待处理的旧指针按下，同时保留其他输入来源的松开事件；设备复位后，新手势在复位之后重新起手。

快捷面板和完整设置都可按 B 取消并收起；收起的角标仍由触屏展开。

控制栏可以调整 30/40/45/60/90/120 帧上限或不限帧、窗口尺寸、抗锯齿、可用的上采样器和原生运动灵敏度。改帧率保持已验证的实时游戏时钟；帧上限不代表设备能稳定达到该帧率。输出尺寸是呈现窗口大小，不冒充内部渲染分辨率。

当前 Linux 后端支持原生尺寸、FSR1、SMAA/TAA；FSR3.1 上采样仍由原有实验能力门禁限制，未启用时不能选择。更完整的已实现选项保留在 All settings。FSR4 不可用，不把空间缩放标成 FSR4。窗口大小由主线程应用；SteamOS 全屏尺寸仍由 Gamescope 管理。设置与停靠位置原子保存到用户游戏数据目录的 savagewind.ini。

运动输入优先读取物理 Deck HID 的 IMU，经融合后提交游戏六轴接口，完全不读取 Steam Input 的鼠标/摇杆陀螺仪映射。Steam Input 继续提供普通按键。启动器只借用传感器模式位，退出时按所有权检查恢复原值。外接有真实 IMU 的手柄可以走 SDL 传感器接口。方向、校准和瞄准效果仍需实机验收。

## 金手指导入

控制栏支持版本绑定的数据补丁开关；当前不内置未经验证的无限体力/无敌地址。`NATIVE_CHEATS_FILE` 可指向 owner-only（0600）的文本文件，缺省在用户游戏数据目录读取 `native-cheats.txt`。格式：

```text
NATIVE_CHEATS_V1 botw-1.6.0 EXACT_64_CHARACTER_NSO_BUILD_ID
# Name module-relative-offset expected-u32 replacement-u32 (all numbers hex)
```

只能使用与当前 build ID 一致、由自己验证的主模块可写数据地址，最多32条，32位对齐；禁止覆盖代码、宿主内存、重复地址或执行脚本。选择开关只排队，在游戏呈现线程检查原值并执行 compare-and-swap；关闭时仅当数据仍为本补丁写入值才恢复，冲突则报错并保留现值。它是可逆的数据补丁导入器，不解释 Atmosphère 指令，也不对任意游戏版本套地址。

软件构建、模拟内存补丁回归与真实游戏行为分开验证；目前 `hardware_validated=false`。

触屏侧栏分为画面、控制、Amiibo、金手指四页；当前能力与执行状态见 [扩展功能](feature5.md)。快捷键不再打开侧栏。
