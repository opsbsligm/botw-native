# 验证范围

## 2026-11-12：预热完成记录修正

完成记录改用带任务计数的 `SWPC2` 格式。只有全部翻译成功、请求的管线全部构建成功且预编译管线缓存保存成功，才原子发布完成记录。失败、取消、跳过管线或记录写入失败均保留可重用缓存，供后续重试；旧格式与损坏记录需要重新检查。`SAVAGEWIND_PRECOMPILE_NO_PIPELINES` 仅执行翻译，不再标记完整预热成功。

远端 Linux 测试使用生产预热引擎和合成着色器归档，覆盖任务失败、取消、跳过、缓存保存失败、记录读写与后续重试。它验证完成判定，不替代真实 GPU 编译和实机帧时序。Deck 全量预热最初发现 24 项翻译失败；修正 TLDS 多重采样变体后，13,869 项中仍有 20 项 SULD/SUST 失败，由问题 #1 继续跟踪，不能据此宣称完整覆盖或无卡顿。

## 2026-11-13：管线预热空指针回归

Deck 上的全量预热在翻译阶段之后发生 SIGSEGV。GDB 定位到 `vk_pso_warm_stage`：临时 `StageBuild` 未设置 `si`，而 `stage_layouts` 读取该指针的运动向量属性。补齐指针，使预热与正常构建使用相同的布局约定。

补齐指针后的 Deck 全量回归成功构建 13,849/13,869 条管线，剩余 20 项正常报错并保留缓存，没有完成记录；但 Vulkan 的正常关闭钩子仍强制退出 0。命令行预热改为显式传递结果到相同的 GPU 等待、缓存保存与快速终止路径，避免自动化将失败当成成功。该修正的实机退出码仍需单独回读；一般游戏退出钩子的既有行为不在此项验收范围。

远端 Linux 回归直接调用生产 `vk_pso_warm_stage`，捕获 Vulkan 调用，覆盖顶点/片元、运动向量开启/关闭、深度钳制变体与失败资源回收；不依赖真实 GPU。`tools/make_synthetic_shader_archive.py --out <新目录>` 生成三个原创最小着色器，生产归档读取器、Maxwell 翻译器与 shaderc 编译均通过。该夹具也可用于独立 GPU 预热回归，不包含游戏数据；测试时使用隔离的 XDG 数据/缓存目录，不能覆盖玩家状态。此处不将合成回归计作完整游戏验收，实机全量预热与其余指令缺口仍需分别核验。

## 历史源码构建验证

更新：2026-11-05。此记录限定本独立工程的源码构建，不替代玩家实机验收。

从空目录生成 1901 个游戏 C 文件，完成完整原生代码编译和最终链接；SDK7 的 80 个版本指令门禁与软件时钟测试通过。

现有输入不含完整 RomFS，另有已知损坏影片；构建器必须拒绝它们，不能用替代影片或空文件伪造成功。 因此尚未验证 `--stage all` 成功生成完整新运行包。只有持有健康、对应版本的完整转储并通过所有阶段，才有可运行个人包。

CI 编译不含游戏数据的公共运行时，并从实际编译命令生成 C/C++ 分析输入。分析器必须成功处理全部编译单元；分析失败或缺少覆盖汇总会使 job 失败。SAST、依赖、密钥、工具链容器扫描保持启用，扫描完成不表示零告警，审查处置以对应 MR 为准。工具链及下载归档摘要记录在 `.gitlab/toolchain.env`。

两款游戏默认设置 60 帧上限；解除原 30 帧限制、软件时钟验证不代表设备稳定 60 帧。实体按键、六轴方向、存档实机兼容、休眠恢复和运行性能由玩家验收；`hardware_validated=false`。

仅允许分享源码导出包。生成的游戏代码、游戏资源、系统字体、个人运行包和存档不属于公共构建产物。
